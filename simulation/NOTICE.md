# Compiled image

VisionX.hex contains the VisionX sketch compiled with the Arduino Uno AVR core and AVR toolchain distributed in [Arduino IDE 1.8.19](https://downloads.arduino.cc/arduino-1.8.19-linux64.tar.xz). The full corresponding core, variant and library sources and notices are in that distribution under hardware/arduino/avr and hardware/tools/avr. Arduino core contributors include David A. Mellis, the Arduino team and Brett Hagman (Tone). Core components carry LGPL terms. AVR-libc carries its upstream BSD-style notices. The VisionX MIT license applies to the original sketch. To rebuild with a modified core, replace that core in the distribution and Verify/Export compiled binary for Arduino Uno using the supplied source.

The display-enabled HEX also includes SSD1306Ascii 1.3.5 by Bill Greiman. See SSD1306Ascii-LICENSE.md and https://github.com/greiman/SSD1306Ascii for sources.
