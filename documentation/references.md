# Sources and design credit

1. Rini Setyowati, Ayu Nurjanah and Mia Monicca Basalama, with mentor Lintang Wisesa Atissalam. [Glove-Eye repository](https://github.com/simplinnovation/Arduino-Glove-Eye), revision c9a761b. The sketch and circuit image show D6 trigger, D5 echo, D12 LED and D13 buzzer. The sketch uses a strict less-than-100 cm check, integer division and a blocking delay. A zero-duration echo enters its alert branch. The paper abstract describes a 40 cm version. The README mentions vibration, while the checked sketch drives only LED and buzzer pins. This distinction matters when comparing versions. The [demonstration video](https://youtu.be/tl9uDUr10xY) was inspected through its description and storyboard frames, which show the red assembly being handled and its paired transducers facing outward. Full motion and audio playback were unavailable, so the video supplies no timing or audible-pattern measurements. No explicit license file was found in the checkout.
2. Shahmeer Hussain and Amna Yousuf Judge. [SSUET Smart Blind Stick](https://github.com/shahmeeerx/Smart-Blind-Stick). Two assembly photographs, a circuit PDF, Proteus capture, report and Arduino sketch document a built prototype. Its code switches a buzzer and LED together below 25 cm. The README lists 25 cm as detected, so the code is the basis of the threshold comparison.
3. garrytho and the project team. [Ultrasonic Distance-Sensing White Cane](https://github.com/garrytho/ultrasonicWhiteCane). Expo photographs and successive firmware versions document their cane enclosure and feedback experiments. VisionX uses these examples as evidence of build approaches. Their photos do not establish VisionX detection rates.
4. Arduino. [Uno R3 hardware and pinout](https://docs.arduino.cc/hardware/uno-rev3/). ELECFreaks. [HC-SR04 module datasheet](https://cdn.sparkfun.com/datasheets/Sensors/Proximity/HCSR04.pdf).
5. Wokwi. [HC-SR04 model](https://docs.wokwi.com/parts/wokwi-hc-sr04), [diagram format](https://docs.wokwi.com/diagram-format), and [AVR8js processor emulator](https://github.com/wokwi/avr8js).

The firmware, net drawings and written material were independently authored. Upstream source, photos and videos are linked for credit. The concept illustration was generated for this project and depicts a proposed assembly.

Display references: [SSD1306Ascii by Bill Greiman](https://github.com/greiman/SSD1306Ascii) and [Wokwi SSD1306 module pinout](https://docs.wokwi.com/parts/board-ssd1306). The simulator supply rating applies to its model.
